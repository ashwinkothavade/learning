# Day 1 Core (Java): runnable workspace
Each file is a skeleton with TODOs, tests in `main`, and a WRITTEN ANSWER spot. Edit in place, then run from the repo root:

    java core-swe/day-01/Ex0_StaticCounter.java
    java core-swe/day-01/Ex1_AccountTransfer.java
    java core-swe/day-01/Ex2_DateRange.java
    java core-swe/day-01/Ex3_Temperature.java
    java core-swe/day-01/Ex4_References.java
    java core-swe/day-01/Ex5_EqualsHashCode.java
    java core-swe/day-01/Ex6_Library.java

Needs JDK 17+. Skeletons fail until you implement them (that is intended). Exit code 0 means all tests passed.
